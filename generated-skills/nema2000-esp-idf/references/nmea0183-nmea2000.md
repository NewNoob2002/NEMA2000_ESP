# NMEA0183 To NMEA2000 Gateway

Use this file when changing parser, GNSS state, or generated NMEA2000 messages.

## Main Files

- `main/nmea0183_to_n2k.h`: public data structures and parser class.
- `main/nmea0183_to_n2k.cpp`: sentence parsing, field validation, GNSS state updates, and message generation.
- `main/main.cpp`: shows intended runtime flow for parser feeding and NMEA2000 message sending, though much of the gateway loop is currently commented.

## Parser Shape

- `tGatewayNmea0183Parser` owns parser state, GNSS state, stats, pending messages, and optional callback.
- `Begin()` allocates/starts the SparkFun parser. Only one active parser instance is supported through a static active parser pointer.
- `FeedByte()` and `FeedBytes()` accept incoming UART/NMEA bytes.
- `TakeMessages()` returns pending generated messages.
- `BuildMessages()` creates messages from the current GNSS state.
- `ResetFix()` clears fix-related state.

## Important Data

- `tGatewayGnssData`: validity flags plus latitude, longitude, SOG, COG, time/date, altitude, HDOP, satellite count, and GNSS method.
- `tGatewayNmea0183Stats`: parsed sentence counts, accepted RMC/GGA counts, unsupported sentence count, checksum and invalid-field counts, generated message count, last sentence, and last error.
- `tGatewayN2kMessages`: generated `LatLonRapid`, `CogSogRapid`, and `Gnss` messages.

## NMEA0183 Handling

- Current logic is centered on GNSS NMEA sentences such as RMC and GGA.
- Validate checksum and fields before mutating state.
- Preserve stats updates when adding or changing sentence support.
- Keep latitude/longitude conversion strict: NMEA degrees/minutes must remain valid for hemisphere and range.
- Preserve date/time validation, including two-digit year handling and days-since-1970 conversion.

## NMEA2000 Output

The gateway transmit list includes:

- PGN `129025`: rapid position.
- PGN `129026`: rapid COG/SOG.
- PGN `129029`: GNSS position data.

When changing output behavior:

- Verify the GNSS validity flags required for each message.
- Use existing NMEA2000 library helpers from `components/NMEA2000/src/N2kMessages.*` where possible.
- Keep `ConfigureGatewayNmea2000()` product/device configuration consistent unless the task is about identity or certification.
- Confirm `SendGatewayMessage()` behavior in `main/main.cpp` if changing send semantics or failure accounting.

## Testing Ideas

- Feed known-good RMC and GGA sentences and verify stats, GNSS fields, and pending messages.
- Feed bad checksum data and verify `BadChecksum` and `LastError`.
- Feed unsupported sentence names and verify `UnsupportedSentences`.
- Feed invalid coordinates, dates, times, or satellites and verify invalid-field handling.
